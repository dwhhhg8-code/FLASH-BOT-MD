### 📦 تنصيب المكتبات

1. **نصّب Git**
   [![Git](https://img.shields.io/badge/Git-F05032?style=for-the-badge&logo=git&logoColor=white)](https://git-scm.com/downloads)
   نزّله ونصّبه واعمل *Next* على طول.

2. **نصّب Node.js**
   [![Node.js](https://img.shields.io/badge/Node.js-339933?style=for-the-badge&logo=nodedotjs&logoColor=white)](https://nodejs.org/en/download)
   نزّله ونصّبه واعمل *Next* على طول.

3. **نصّب ImageMagick**
   [![ImageMagick](https://img.shields.io/badge/ImageMagick-000000?style=for-the-badge&logo=imagemagick&logoColor=white)](https://imagemagick.org/script/download.php)
   أثناء التنصيب، في **Select Additional Tasks** فعّل خيار:
   **✔ Install legacy utilities (e.g. convert)**.
   وبعدها كمل *Next* لحد ما يخلص.

4. **نصّب [`FFmpeg`](https://ffmpeg.org/download.html)**
   [![FFmpeg](https://img.shields.io/badge/FFmpeg-007808?style=for-the-badge&logo=ffmpeg&logoColor=white)](https://www.gyan.dev/ffmpeg/builds/)
   - نزّل وفكّ الضغط.
   - سمّي المجلد **FFmpeg**.
   - اعمل مجلد في `C:\Bots`
   - انقل المجلد لـ: `C:\Bots\FFmpeg`.
   - ادخل `C:\Bots\FFmpeg\bin` وانسخ المسار.
   - في بحث ويندوز اكتب **"تعديل متغيرات البيئة للنظام"** وافتحه.
   - في النافذة اللي هتظهر روح لـ **متغيرات البيئة** ← اختار **Path** مرتين في متغيرات المستخدم ← **جديد** ← الصق المسار اللي نسخته.
   - اقبل (تلات مرات) لحد ما يتسجّل.
   - افتح `cmd` كمسؤول وروح:
     ```bash
     cd ..
     ```
     لحد ما توصل لـ `C:\`
     وبعدها:
     ```bash
     cd Bots
     ```
   - اتأكد إن كل حاجة شغالة:
     ```bash
     git --version & node -v & magick -version & ffmpeg -version
     ```
